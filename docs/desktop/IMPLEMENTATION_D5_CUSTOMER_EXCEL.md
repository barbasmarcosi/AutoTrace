# Informe XLSX para un cliente — incremento implementado

El cliente se selecciona desde su ficha. Se exportan exclusivamente sus vehículos y servicios. Se excluyen costos de repuestos/mano de obra, notas privadas, VIN, IDs internos, márgenes y datos de otros propietarios. El archivo tiene formato de reporte con hojas Resumen/Vehículos/Servicios, incompatible con el importador de respaldos completos. Se requieren todavía revisión visual con Excel y prueba en una instalación Windows real; el PR sigue en Draft.
